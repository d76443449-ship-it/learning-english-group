# Learning English Group — English Moja 25 Classes

This is the simple version without Notes or Firebase.

## Included
- 25 class cards
- All 25 Google Drive folder links already added
- Each class opens its own Google Drive video folder
- Mobile responsive
- Ready for GitHub Pages

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload all files from this folder.
3. Go to Settings → Pages.
4. Select Deploy from a branch.
5. Select `main` and `/(root)`.
6. Save.

Make sure all Google Drive folders are shared as:
**Anyone with the link → Viewer**
